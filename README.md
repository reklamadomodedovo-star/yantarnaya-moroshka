# Янтарная Морошка — сайт салона красоты

Промо-сайт салона красоты «Янтарная Морошка» (г. Домодедово, ул. Гагарина, 49)
по ТЗ v1.0. Статический сайт без сборщиков — чистый HTML/CSS/JS.

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Главная: hero, о салоне, услуги, преимущества (CountUp), до/после, основательница, мастера, отзывы, блог, FAQ, контакты с Яндекс.Картой |
| `uslugi/*.html` | 5 страниц услуг (волосы, ногти, лицо, тело, брови) с прайсами и локальным SEO |
| `blog/*.html` | 3 статьи блога с блоками «Читайте также» и CTA |
| `assets/css/style.css` | Дизайн-система на основе логотипа (шалфей #525E3D, янтарь #F99F1E, олива #6C7445) |
| `assets/js/main.js` | Слайдер до/после, карусель, аккордеон, модалка записи, маска телефона |
| `assets/img/` | Логотип, фирменный фавикон, фото (сейчас — временные, заменить на реальные) |
| `build_pages.py` | Генератор страниц услуг/блога: `python3 build_pages.py` |

## Локальный запуск

```bash
cd moroshka-site
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Деплой

Сайт статический — подходит для GitHub Pages: настройки репозитория →
Pages → Branch: `main` → `/ (root)`. Ссылка вида
`https://<username>.github.io/<repo>/`.
